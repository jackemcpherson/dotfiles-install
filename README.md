# dotfiles-install

**Deprecated on 2026-09-18.** The `dotfiles` CLI is now distributed through
the public Homebrew tap
[`jackemcpherson/homebrew-tap`](https://github.com/jackemcpherson/homebrew-tap):

```bash
brew install jackemcpherson/tap/dotfiles
```

This repository is archived. `install.sh` stays for old links but the
private releases it downloaded are no longer published; new versions only
reach the tap.
